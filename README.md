
# Chat-log-for-PonyMeadow

Расширение для браузера Google Chrome, добавляющее удобное окно с историей сообщений игроков на сервере игры PonyMeadow. 
Это временное решение, пока создатель не добавит этот функционал в игру.

## Установка

1. Клонируйте репозиторий: `git clone https://github.com/...`

2. В Chrome перейдите в `chrome://extensions/`

3. Включите «Режим разработчика»

4. Нажмите «Загрузить распакованное расширение» и выберите папку проекта

## Функционал

Добовляет последнее сообщение игроков/игрока в окно "история чата"

## Работоспособность 

Проверено на версии игры 0.0.2
